## 自走テストハーネス設計

エージェントが人間の介入なしに各イテレーションを判定するための検証基盤。

- **非干渉性の目的**: OS APIを一律に禁止するのではなく、同じコンピュータ上のユーザー作業を妨げない。OS入力、フォーカス/前面ウィンドウ、可視ウィンドウ操作、実デスクトップキャプチャ、実スピーカー・マイクを使用せず、ヘッドレス/オフスクリーン実行、プロセス内API、隔離した仮想デバイス、固定パスへ出力する観測物を使う: ...
- **非干渉手段の逸脱禁止**: 前面化、ウィンドウ操作、入力注入、デスクトップキャプチャを検証手段に使わない。これらでしか確認できない項目は自動検証対象外として記録する: ...
- **統一エントリポイント**:
  - `setup`: 依存導入・初期化（例: `...`）
  - `run`: 成果物の起動（例: `...`）
  - `verify`: 全自動検証の実行（例: `...`）— **exit 0 = 全検証項目の完了**
- **判定方式**: exit code / 構造化ログ（JSONL）/ スナップショット / HTTP レスポンス / **エージェントによる画像のマルチモーダル直接確認** のうち採用するもの
- **マルチモーダル確認の運用**: 隔離したテストプロセスが画像を固定パスへ出力し、Codexが「期待される表示状態」と一致するか判定する。デスクトップ、他アプリ、ユーザーの作業内容を含むキャプチャは使用しない。判定基準は各イテレーションで明記する
- **非干渉性の構造的保証**: ヘッドレス/オフスクリーン指定を固定している箇所、キャプチャ元がオフスクリーンターゲットであること、OS入力・デスクトップキャプチャ系APIを依存に含めないこと: ...
- **非干渉性の実行時検証**: 非干渉性が起動時に解決される環境状態に依存する場合のみ記載する。依存しない場合は「不要」と書く
  - 対象サブシステムと期待値（実際に使うものだけ。例: display = `headless` / capture = offscreen / audio = dummy）: ...
  - 解決後の状態の取得方法（ランタイムAPIへの問い直し。例: `DisplayServer.get_name()`。設定値のエコーバックは不可）: ...
  - 読み戻しAPIがない場合の代替（環境前提の検証。例: `DISPLAY`と`WAYLAND_DISPLAY`がいずれも未設定）: ...
  - 検証タイミングはハーネス起動時に1回。fail条件は解決後の状態が期待値と異なることのみ（メタデータの欠落はfailにしない）
  - 構造上ヘッドレス化できない対象（例: GUIのEditorを経由するテスト）: 「自動検証対象外（既知の制約）」に理由を記載: ...
- **再現性の確保**: 乱数シード固定、時刻のモック、外部依存（ネットワーク・DB・LLM など）のスタブ化方針
- **観測物の保存先**: ログ・スクリーンショット・スナップショットの固定パス
- **失敗時のデバッグ手順**: どのファイルを見れば原因が分かるか
- **権限昇格時の判断**: WindowServer、Accessibility、画面収録、入力監視等の権限を要求する前に非干渉性を確認し、禁止操作が必要なら自動検証を停止して自動検証対象外として記録する

## イテレーション計画

- 検証項目はすべてエージェントが非干渉な`verify`と成果物で pass/fail を判定できるものとする。非干渉性の検証はハーネス起動時に1回行うため、各イテレーションでは再掲せず自分の判定基準だけを書く。
- **イテレーション完了 = タスク完了 + `verify`のexit 0**。人間の確認は完了条件に含めない。

### Iteration 1: （タイトル）

**ゴール**: このイテレーションで達成すること

**確認できる成果物**: 何が目で見て確認できるか（必須）

**タスク**:

- [ ] ...
- [ ] ...

**検証項目**（必須・1つ以上）: エージェントが非干渉な方法でpass/fail判定できるもの

- [ ] 実行コマンド: `...` / 判定: exit 0、ログに `...` を含む
- [ ] 実行コマンド: `...` / 判定: スナップショット `path/to/golden.png` と一致
- [ ] 実行コマンド: `...` で `artifacts/screenshot.png` を生成 / 判定: エージェントが画像を直接確認し「〇〇ボタンが赤色で中央に表示」「エラーメッセージが日本語で表示」などの期待状態と一致
