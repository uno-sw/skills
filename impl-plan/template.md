## 自走テストハーネス設計

エージェントが人間の介入なしに各イテレーションの完了を判定するための検証基盤。

- **OS 入出力からの隔離**: E2E 検証では OS レベルのマウス・キーボード入力、フォーカス/前面ウィンドウ、実デスクトップ表示、実スピーカー・マイクを使用しない。ヘッドレス/オフスクリーン実行、プロセス内 API、隔離した仮想デバイス、固定パスへ出力する観測物を使い、同じコンピュータ上のユーザー操作と相互干渉しない構成にする: ...
- **統一エントリポイント**:
  - `setup`: 依存導入・初期化（例: `...`）
  - `run`: 成果物の起動（例: `...`）
  - `verify`: 全自動検証の実行（例: `...`）— **exit 0 = 完了**
- **判定方式**: exit code / 構造化ログ（JSONL）/ スナップショット / HTTP レスポンス / **エージェントによる画像のマルチモーダル直接確認** のうち採用するもの
- **マルチモーダル確認の運用**: スクリーンショットなどを固定パスへ出力し、Codex が利用可能な画像表示・検査手段で画像を読み込んで「期待される表示状態」と一致するか判定する。判定基準（何が映っていれば pass か）は各イテレーションで明記する
- **再現性の確保**: 乱数シード固定、時刻のモック、外部依存（ネットワーク・DB・LLM など）のスタブ化方針
- **観測物の保存先**: ログ・スクリーンショット・スナップショットの固定パス
- **失敗時のデバッグ手順**: どのファイルを見れば原因が分かるか
